# Secretary General Map Editor
The map editor is forked from OpenGS for specialized usage within Twelve star games. 
This fork and its unique assets and code are private property of Twelve Star games and is NOT covered by the MIT licence of the original project.

## Features
- Selectable provinces
- Toggleable map modes
- Map in 3D environment
- Dynamic Smooth borders (SDF borders calculated w JFA)
- Dynamic country name labels
- 3D environment from Heigthmap and Normal map
- Editable Provinces through ingame editor
